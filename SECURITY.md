# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues, discussions or pull requests.

Report them privately through GitHub's private vulnerability reporting:
[open a draft security advisory](https://github.com/wtf-corp/yaf-backend-framework/security/advisories/new).

Say what is affected, how to reproduce it and what an attacker could do with it. Do not include real credentials or personal data.

## What happens next

- We acknowledge the report within 5 working days.
- We publish a fix or a security advisory within 90 days of the report.
- We keep you informed in the advisory and credit you there, unless you ask us not to.

Please keep the details private until the fix or the advisory is published.

## Supported versions

Until `1.0.0`, only the latest prerelease receives security fixes. Older prereleases do not: upgrade to the latest one.
