# Contributing to YAF

Thank you for helping. This file only tells you where the rules are; it does not repeat them.

## The same rules for everyone

Humans and AI agents follow the same rules here. There is no separate, lighter path for either.

## Where the rules are

- [`AGENTS.md`](AGENTS.md): how work happens, the commands, the hard rules, the conventions and when to stop and ask. Read it before your first change, and the nested `AGENTS.md` of the tree you work in.
